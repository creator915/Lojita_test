# Native binary path

## 任务

对不需要在运行时搬运高阶同伦数据的程序，使用未修改的 Stock Agda 完成：类型检查 → MAlonzo → 类型擦除 Haskell → 用户选择的 GHC → 本机二进制。此目录必须能独立构建和测试，不依赖另外两条路径或分流器。

## 接口边界

- 输入：Agda 工程、入口模块及显式工具/库配置。
- 输出：可执行文件、生成源码审计和可复现的 provenance。
- 本路径不得嵌入 runtime NbE，也不得生成跨进程 `Term` packet。
- 适用性判断必须保守；不能确认时 fail-closed。

## 验收标准

- 真实 Stock Agda/MAlonzo/GHC 链路编译并运行普通与擦除型 Cubical 正例。
- 审计生成 Haskell 的类型擦除，以及最终二进制的符号和动态依赖。
- 动态高阶搬运、类型错误、身份变化和陈旧产物均稳定拒绝且不发布产物。
- 提供本目录独立测试入口；工具均可覆盖或从 `PATH` 探测，测试记录实际版本。
- 不得用预生成 Haskell、mock 编译器或缓存二进制冒充链路成功。
